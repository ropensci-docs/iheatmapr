# ColumnPlot

Class for storing generic column plot

## Slots

- `xaxis`:

  name of xaxis

- `yaxis`:

  name of yaxis

- `data`:

  vector of values

- `name`:

  tracename

- `type`:

  trace type

- `showlegend`:

  show the legend?

- `additional`:

  additional plotly parameters
