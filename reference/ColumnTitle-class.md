# ColumnTitle

Class for storing column title

## Slots

- `xaxis`:

  name of xaxis

- `yaxis`:

  name of yaxis

- `data`:

  the title (character)

- `side`:

  side of plot on which dendrogram is positioned, controls orientation

- `textangle`:

  angle for text

- `font`:

  list of font attributes
