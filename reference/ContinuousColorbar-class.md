# ContinuousColorbar

Class for storing continuous colorbar information

## Slots

- `title`:

  title for colorbar

- `position`:

  integer indicating relative position of colorbar

- `colors`:

  name of color palette or vector of colors

- `zmid`:

  midpoint of colorbar

- `zmin`:

  min of colorbar

- `zmax`:

  max of colorbar
