# IheatmapAxis

Class for storing axis information

## Slots

- `id`:

  plotly id for axis

- `domain_start`:

  start of domain (0 to 1)

- `domain_end`:

  end of domain (0 to 1)

- `anchor`:

  anchor for axis

- `layout`:

  plotly layout parameters
