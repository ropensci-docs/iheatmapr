# IheatmapMainX

Class for storing X axis information for "main" x axis– x axis for
[`MainHeatmap-class`](https://docs.ropensci.org/iheatmapr/reference/MainHeatmap-class.md)

## Slots

- `id`:

  plotly id for axis

- `domain_start`:

  start of domain (0 to 1)

- `domain_end`:

  end of domain (0 to 1)

- `anchor`:

  anchor for axis

- `layout`:

  plotly layout parameters

- `categorical`:

  is axis categorical?

- `order`:

  ordering of columns

- `text`:

  text labels for columns
