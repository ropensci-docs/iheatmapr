# MainHeatmap

Class for storing main heatmap

## Slots

- `xaxis`:

  name of xaxis

- `yaxis`:

  name of yaxis

- `data`:

  matrix of heatmap values

- `colorbar`:

  name of colorbar

- `show_colorbar`:

  show the colorbar?
