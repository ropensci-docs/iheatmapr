# RowAnnotation

Class for storing row annotation

## Slots

- `xaxis`:

  name of xaxis

- `yaxis`:

  name of yaxis

- `data`:

  vector of annotation values

- `colorbar`:

  name of colorbar

- `show_colorbar`:

  show the colorbar?
